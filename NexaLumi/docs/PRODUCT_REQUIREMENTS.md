# Product requirements (Phase 0–1)

Source of truth: `NEXALUMI_PRODUCT_BRIEF.md`. Public URL: https://trynexalumi.com

## Goals for this milestone

- Ship a responsive website people can browse on desktop, tablet, and phone.
- Explain NEXALUMI without fear-based copy or “100% safe” claims.
- Let users try Link Check and Message Check as labelled Demo flows.
- Keep raw message content out of persistent storage.

## In scope

Landing, auth UI, dashboard, link check, message check, scan history, settings, help, privacy, terms, contact.

## Out of scope (later phases)

Managed authentication, PostgreSQL, live threat-intelligence providers, email/QR checks, notifications, admin console, native apps.
